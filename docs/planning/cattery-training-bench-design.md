# 猫咪实训台：十级永久工作效率家具

2026-09-06。替代此前五级候选，按用户确认的十级曲线实现。权威配方为 `packages/game-data/source/json/cattery_furniture.json` 中的 `kitty_training_bench`；不是待实现的概念 DSL。

## 成长与作用

每账号一件，全账号现有及未来取得的合格猫咪共享。安置就是 Lv1，最高 Lv10，只能逐级升级；一次性扣库存，永久有效，无维护、无耐久、无启停、无拆卸退款。不扩大动作资格，不绕过等级、配方、装备与原料要求。

以上未计装备、性格等加成。基础 -100% 表示耗时翻倍，不是无法行动。家具是效率加值，不是耗时每级乘固定系数；装备与其他修正仍然保留。满级相对于未安置、无其他修正时的工作吞吐量约为 2.8 倍，而非额外发放经验或产物。

作用范围：采集、采矿、养殖、制作、缝纫、锻造、炼金、烹饪。钓鱼、战斗攻速/行动条、委托、强化、建造不参与。沿用猫咪最低基础耗时倍率 0.5 和公共动作最短耗时，不覆盖专门动作的既有计时规则。

书桌单次经验分享比例不变，但单位时间完成更多工作，分享经验与工作原料消耗随之增加。书桌/柜子的维护计时和战斗概率不受影响。

## DSL 与运行边界

- `Definition.service` 为 `permanent` 或 `prepaid`，缺省兼容旧的 prepaid。永久模式严格禁止维护配方、时长及补给/启停命令。
- 独立家具最高等级由自身 levels 决定；书桌/柜子仍为六级。定义与冻结来源最多支持十级。
- 通用效果 `action_efficiency_add / action_start`，以 `rateBps` 表示效率百分点，实训台曲线为 2000、4000、6000、8000、10000、10800、11600、12400、13200、14000。
- 同一来源重叠规则取最大值，不重复叠加；不同来源相加。显式工作类型白名单限制钓鱼等系统不受影响。
- 共用 `resolveWorkDurationTx` 在现有属性总值后叠加效率，不修改任何猫咪属性行。通用动作、料理制作和炼金执行器只适配计时协议，不包含家具 ID 或升级数值分支。
- `timingEffects` 冻结每次开始的来源版本、等级与规则。缺省是旧存档无效果；装备触发当前动作时间刷新时保留该动作原家具快照。
- 永久来源用 SQL NULL 结束时间表达无界，不使用多年后到期日期；共用窗口加载器理解 NULL。来源在安装/升级事务中写入，无后台倒计时任务。

## 在线、离线与事务

安置/升级沿用用户锁、revision、30 秒报价及幂等回执。库存不足、旧报价、重复请求不会提交部分等级/扣费。库存可能被历史待结算动作占用时返回恢复中，不挪用其原料，不做无限补算。

生效边界 T：正在执行的动作保持原耗时；逻辑开始时间在 T 之前的工作用旧效果，在 T 及之后用新效果。重连和离线分片不得把当前等级追溯应用到旧工作。

同一效果期间继续批量结算。每个会话对效率边界排序建索引，通过二分搜索找到下一边界；只在跨等级/规则/有效期边界时拆批并重开一次计时。不逐动作查家具，不增加每只猫的属性写入，也不创建额外数据库表或后台任务。

实训台不生成额外奖励归因记录。真实动作收益正常结算，书桌/柜子的已有贡献报告保留，不伪造“额外完成次数”或反事实经验。

## 前端

家具工坊展示独立实训台图标、等级/上限、效率加值、未计其他加成的基础效率，以及永久生效状态。隐藏不适用的维护栏、补充按钮、开关、剩余时间与空收益统计。

升级确认显示前后效果及唯一一组总需求；无维护补差时不重复显示同一材料清单。材料仍为图标、名称、需求(库存)，不足用原有危险色，移除标签下单列“缺少 X”。标签顶部对齐，不因另一项换行而纵向拉伸。

移动端选择区自动换行，材料完整换行，确认对话框可滚动。动作详情和生产规划读取同一家具投影进行效率预览，时长按后端毫秒与最短耗时口径显示。动作详情另外标注家具效率贡献；未加载投影时先拉取，不每个动作单独请求。

## 部署与验证边界

已有家具系统的数据库，部署前人工执行 `server/schema/migrations/20260906_cattery_furniture_permanent.sql`，然后同版部署 server、action-worker、其他读取效果的 worker、前端和生成数据。全新数据库使用更新后的 init.sql。旧版本程序不能解释永久窗口与新规则，不应与新版混跑；回滚前需另做版本兼容处理。

本轮没有对现有玩家数据库执行迁移。临时 PostgreSQL 表测试会执行迁移验证可重复运行，不触及现有玩家表。

验证包括十级曲线、永久服务约束、材料引用、冻结边界、当前动作不追溯、在线/离线不同分片、恒定等级保留批量、安装升级幂等和失败回滚、桌面与窄屏 UI。浏览器隔离 harness 使用模拟库存，不能冒充真实账号端到端扣费验证。
